# Delikatesy Zibra — strona internetowa

Strona sklepu Delikatesy Zibra (Legionów 50, Wołomin) w stylu „liquid glass”.

Czysty HTML/CSS/JS — bez budowania. Żeby uruchomić lokalnie, otwórz `index.html`
albo odpal dowolny serwer statyczny, np. `npx serve .`.
Na Vercel wystarczy zaimportować repozytorium (framework: „Other”).

- `index.html` — treść strony
- `style.css` — wygląd (materiał szkła: klasa `.glass`)
- `script.js` — status „otwarte/zamknięte” na żywo, animacje przy przewijaniu, menu mobilne
- `assets/` — logo i zdjęcia produktów
